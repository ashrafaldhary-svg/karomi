# كرومي (Karomi) — تطبيق تحميل فيديو وصوت للاستخدام الشخصي

تطبيق Android لتحميل الفيديوهات والصوتيات من منصات مشاركة الفيديو، **للاستخدام الشخصي فقط**.

> ⚠️ **تنبيه قانوني**: هذا التطبيق مخصص للاستخدام الشخصي فقط. يُمنع منعًا باتًا إعادة توزيع أو نشر أي محتوى يتم تحميله، واحترم حقوق الملكية الفكرية وشروط استخدام المنصات.

## المميزات

- 🎨 واجهة عربية بسيطة (RTL كامل) مع وضع ليلي اختياري
- 🔗 لصق الرابط تلقائيًا من الحافظة أو المشاركة من أي تطبيق
- 📥 تحميل بجودات متعددة: 1080p / 720p / 480p (MP4) وصيغ WEBM
- 🎵 استخراج الصوت وتحويله إلى AAC (M4A) أصليًا، وMP3 عبر نقطة تكامل FFmpeg
- 📊 عرض الحجم التقريبي لكل جودة قبل التحميل
- ⚡ تحميل متعدد الخيوط بطلبات HTTP Range (تسريع حتى 3 أضعاف)
- 🔔 تحميل في الخلفية (Foreground Service) مع إشعار تقدم مباشر
- ⏸️ إيقاف مؤقت واستئناف التحميل في أي وقت (يُحفظ تقدم كل جزء)
- 📚 مكتبة تحميلات مع قائمة تشغيل ذكية وتشغيل مباشر داخل التطبيق (ExoPlayer)
- 🗂️ حذف أو نقل الملفات إلى مجلدات مخصصة (Videos / Music / Downloads)
- 💾 نسخ احتياطي واستعادة لقائمة التحميلات (JSON)
- 🔄 فحص التحديثات من الموقع الرسمي فقط
- 📱 يدعم Android 5.0 (API 21) فما فوق
- 🔒 لا يطلب أي أذونات غير ضرورية (لا جهات اتصال، لا موقع)

## بنية المشروع

```
app/src/main/java/com/karomi/downloader/
├── KaromiApp.kt              # نقطة الدخول: الوضع الليلي + قناة الإشعارات
├── data/                     # Room: كيان التحميل + DAO + قاعدة البيانات
├── download/
│   ├── MultiThreadDownloader.kt  # تحميل متعدد الخيوط مع استئناف
│   └── DownloadService.kt        # خدمة أمامية + إشعارات التقدم
├── extractor/
│   ├── VideoExtractor.kt         # استخراج الجودات والأحجام (نقطة تكامل yt-dlp)
│   └── AudioExtractor.kt         # استخراج AAC/M4A عبر MediaMuxer
├── library/PlaylistManager.kt    # قوائم تشغيل ذكية + نسخ احتياطي JSON
├── ui/                         # الشاشات: الرئيسية، المكتبة، الإعدادات، المشغّل
└── util/                       # تنسيق الأحجام + فحص التحديثات
```

## البناء

```bash
./gradlew assembleDebug
```

يتطلب Android Studio Hedgehog أو أحدث و JDK 17.

## ملاحظة حول استخراج الجودات من المنصات

الروابط المباشرة لملفات الوسائط تعمل بالكامل. لاستخراج جودات YouTube وغيرها،
ادمج مكتبة `youtubedl-android` في `VideoExtractor.extractFromPlatform()` —
الكود جاهز بنقطة تكامل موثقة، مع الالتزام بالاستخدام الشخصي فقط وشروط المنصات.
